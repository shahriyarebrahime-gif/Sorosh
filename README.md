# فروشگاه آنلاین دفتر فنی و لوازم التحریر سروش

## اجرای محلی
```bash
npm install
npm run build
npm start
```

## Render
- Runtime: Node
- Root Directory: خالی، اگر package.json در ریشه Repository است.
- Build Command: `npm run build`
- Start Command: `npm start`
